# Galería

1. Copie aquí las mejores fotos (JPG/WebP, ancho ~1200 px, < 300 KB cada una).
2. Enumérelas en `gallery.json`:

```json
[
  { "src": "assets/gallery/colchon-queen.jpg", "alt": "Colchón ortopédico Queen", "title": "Descanso real" },
  { "src": "assets/gallery/freidora.jpg", "alt": "Freidora de aire", "title": "Cocina más fácil" }
]
```

Mientras `gallery.json` esté vacío, el sitio muestra mosaicos animados de la marca.
